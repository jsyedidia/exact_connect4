# src/bin/exact_connect4_solver.rs

## Role In The System

`src/bin/exact_connect4_solver.rs` is the command-line frontend for the exact
solver. It reads one move sequence per input line, parses each sequence into a
`Position`, and prints either a single perfect-play score or one score per
column.

The binary loads the embedded default opening book unless the user passes
`-b FILE`, in which case it attempts to load that file instead.

`Options` is generated by `clap`. The command metadata controls the help output.

```rust
    #[arg(short = 'a')]
    analyze: bool,

    #[arg(short = 'w')]
    weak: bool,

    #[arg(short = 'b', value_name = "FILE", default_value = exact_connect4::DEFAULT_OPENING_BOOK_PATH)]
    opening_book: PathBuf,
}
```

`-a` switches from one score to seven column scores. `-w` uses the weak
win/draw/loss solver. `-b FILE` selects an opening-book file, defaulting to the
tracked book path.

### Main Function

```rust
fn main() -> ExitCode {
    let options = Options::parse();
```

`main` starts by parsing command-line options.

```rust
    let mut solver =
        if options.opening_book.as_path() == Path::new(exact_connect4::DEFAULT_OPENING_BOOK_PATH) {
            exact_connect4::solver::Solver::new()
        } else {
            let mut solver = exact_connect4::solver::Solver::without_book();
            if let Err(error) = solver.load_book_from_file(&options.opening_book) {
                eprintln!(
                    "Unable to load opening book {}: {error}",
                    options.opening_book.display()
                );
            }
            solver
        };
```

The default path uses `Solver::new`, which loads the embedded default book. A
custom path starts with a no-book solver and then attempts to load the requested
file. If loading fails, the program reports the error and continues without a
book.

```rust
    let stdin = io::stdin();

    for (line_number, line) in stdin.lock().lines().enumerate() {
        let line = match line {
            Ok(line) => line,
            Err(error) => {
                eprintln!("Line {}: {error}", line_number + 1);
                return ExitCode::from(1);
            }
        };
        let sequence = line.trim_end_matches('\r');
```

The program reads stdin line by line. IO failures stop the program with a
nonzero exit code. A trailing carriage return is removed so CRLF input works.

```rust
        let position = match exact_connect4::position::Position::from_sequence(sequence) {
            Ok(position) => position,
            Err(error) => {
                eprintln!("Line {}: {error} in {sequence:?}", line_number + 1);
                continue;
            }
        };
```

Each input line is parsed as a sequence of 1-based column digits. Invalid
positions are reported on stderr and skipped.

```rust
        print!("{sequence}");
        if options.analyze {
            for score in solver.analyze(&position, options.weak) {
                print!(" {score}");
            }
        } else {
            print!(" {}", solver.solve(&position, options.weak));
        }
        println!();
    }
```

Successful lines always begin their output with the original sequence. Analysis
mode appends seven scores. Normal mode appends one score.

```rust
    ExitCode::SUCCESS
}
```

If all input was read successfully, the process exits successfully. Invalid
positions do not make the process fail; they only skip output for that line.
